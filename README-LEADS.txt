SITE COM BANCO DE LEADS

1) No Windows, dê dois cliques em iniciar-site.bat.
2) Aguarde aparecer: Running on http://127.0.0.1:5000
3) Abra no navegador: http://127.0.0.1:5000
4) Painel de leads: http://127.0.0.1:5000/admin
5) Senha inicial: admin123

IMPORTANTE ANTES DE PUBLICAR:
- Troque a senha administrativa usando a variável de ambiente ADMIN_PASSWORD.
- Troque a SECRET_KEY.
- Use HTTPS na hospedagem.
- O banco fica em data/leads.db.
- O painel permite exportar todos os leads em CSV.

O botão "Baixar material completo" do Casa Prado só libera o PDF depois do cadastro e do aceite de consentimento para contato.
